# 프로젝트 브랜드 가이드 및 시스템 설계 요구사항 정의서 (PRD)

## 1. 프로젝트 개요

- **프로젝트명:** MNF-Nexus (엠엔에프 넥서스)
  - *의미:* 플레이어(손님), 딜러(직원), 운영진(사장님)을 하나로 매끄럽게 연결하는 매장의 중심 콘솔 및 데이터 허브.
- **개발 배경:** 기존 PC 중심의 무겁고 정적인 장부 시스템을 탈피하여, 스태프들이 현장에서 스마트폰(모바일)으로 신속하게 조작하고 카카오톡 단체방 중계 및 실시간 장부 정산을 원터치로 해결하는 하이엔드 모바일 최적화 솔루션 구축.

---

## 2. 핵심 아키텍처 및 기술 스택

| 영역 | 기술 |
|------|------|
| **프론트엔드 (Frontend)** | Next.js (App Router 기반), Tailwind CSS |
| **백엔드/데이터베이스 (Backend/DB)** | Supabase (PostgreSQL) |
| **외부 연동** | 개인 구글 스프레드시트 API 백업망 연동 |
| **배포 인프라 (Deployment)** | Vercel (GitHub 연동형 자동 배포 파이프라인 구축 완료) |
| **디자인 테마** | 다크 모드 기반의 네온 핑크 & 보라색 액센트 컬러를 활용한 세련된 하이엔드 펍 감성 인터페이스 |

## 3. 기능 요구사항 (Functional Requirements)

### [1] 직원용 모바일 조작 화면 (`/staff` 또는 메인 홈)

- **모바일 핑거 최적화 레이아웃:** 엄지손가락으로 쉽게 터치할 수 있는 큼직한 버튼 배열 및 하단 마스터 바 배치.
- **테이블별 실시간 상태 관리:** 1번 테이블부터 10번 테이블까지의 활성화 상태, 현재 블라인드 단계, 리바인 횟수, 총 칩 양 실시간 대시보드 표시.
- **⚡ 원터치 카카오톡 실시간 중계 시스템:**
  - **인텐트 스키마(KakaoTalk Intent Schema) 연동:** 버튼 터치 시 스마트폰의 카카오톡 앱이 강제로 자동 실행되며 단체방 선택 창으로 다이렉트 이동.
  - **줄바꿈 및 이모티콘 완벽 보존:** 블라인드 레벨, 리바인 카운트, 현재 팟 상황이 이쁜 텍스트 양식 그대로 복사 및 전달.
  - **카카오 JS SDK(공유하기) 확장성:** 필요에 따라 깔끔한 카드 박스 형태의 템플릿 전송 모듈 레이어 확보.

### [2] 포커 타이머 및 게임 엔진

- **하이브리드 블라인드 타이머:** 매장 메인 TV 화면(대형 디스플레이) 연동용 레이아웃 및 직원 모바일 싱크.
- **실시간 확률 계산기 (Poker Odds Calc):** 올인 상황 및 특정 핸드 간의 승률을 수학적으로 계산하여 화면에 표시해 주는 하이엔드 컴포넌트 탑재.

### [3] 장부 및 정산 시스템 (보안/데이터 정책)

#### 영구 누적 저장 (초기 프로토타입 정책)

디버깅과 버그 추적, 초기 사장님들 검증을 위해 모든 거래 로그, 외상 장부, 출퇴근 기록은 데이터베이스에 통으로 누적 저장함.

- **필수 구조:** 모든 테이블 생성 시 타임스탬프(`created_at`) 칼럼을 무조건 생성하여 기록함.

#### 2주 주기 자동 파기 스케줄러 (최종 출시 정책)

시스템 안정화 이후 보안 리스크 방어를 위해 매일 새벽 5시, 생성된 지 14일(2주)이 지난 상세 거래 기록(logs)을 데이터베이스에서 자동 파기하는 스케줄러(Cron Job) 탑재 예정.

- 데이터 파기 직전, 사장님 개인 구글 시트로 전체 데이터 자동 백업 API 구동.

## 4. 향후 개발 로드맵 및 동선

### 1단계: 프론트엔드 UI 이식 (현재 단계)

- Stitch(v0)에서 구현한 컴포넌트 코드를 `app/page.tsx`에 이식.
- 모바일 해상도 뷰포트 고정 및 Tailwind CSS 스타일링 에러 정정.

### 2단계: Supabase 데이터베이스 연동

- 실시간 테이블 정보 갱신을 위해 Supabase Client 코드 탑재.
- `created_at` 타임스탬프를 포함한 테이블 스키마 설계 및 마이그레이션.

### 3단계: 카카오톡 원터치 중계 및 딜러 편의 기능 고도화

- `kakaolink://` 스키마 및 인텐트 코드 테스트 및 연타 방지 리바인 버튼 구현.

### 4단계: 백업망 및 파기 기능 추가 (최종 단계)

- 구글 스프레드시트 연동 API 구현 및 2주 자동 삭제 스케줄러 세팅 후 프로덕션 배포.
